Levantamento de Requisitos do Projeto

Requisitos Funcionais (RF)

  • RF01: Cadastrar, editar, listar e excluir moradores.
  • RF02: Registrar e atualizar solicitações de moradores.
  • RF03: Buscar/filtrar moradores por nome, CPF ou bairro.
  • RF04: Exibir métricas da comunidade no dashboard.

Requisitos Não Funcionais (RNF)

  • RNF01: Interface responsiva para mobile e desktop.
  • RNF02: Paleta visual baseada em tons de verde.
  • RNF03: Persistência local de dados (LocalStorage).
  • RNF04: Código limpo usando HTML, CSS e JS nativo.
